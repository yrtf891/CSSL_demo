# CSSL interactive demo (anonymous)

Static website: open `index.html`. No build step, no server code, no tracking.

Contents
- `index.html` - the demo page
- `media/` - animations (MP4) and qualitative figures
- `interactive/` - embedding explorer, Silhouette curves, prediction viewer (self-contained HTML)

Anonymous hosting: put this folder in the code repository as `docs/` (or on a `gh-pages` branch),
then anonymize the repository at https://anonymous.4open.science and enable its website option.
